# 🖥️ macOS Desktop Portfolio

A interactive, responsive macOS-inspired portfolio website built with HTML5, CSS3, and Vanilla JavaScript. Features window management, draggable widgets, custom dock icons, embedded video player modals, and modular project cards.

🚀 **Live Site:** [https://vijeshg.github.io/](https://vijeshg.github.io/)

---

## ✨ Features

- **macOS Translucent Top Bar:** Real-time clock, dynamic branding menu, and desktop shortcuts.
- **Interactive Windows:** macOS Finder-style floating windows for **Projects**, **About Me**, and **Contact** with close, minimize, and maximize controls.
- **Draggable Widgets & Icons:** Functional analog clock, calendar widget, and draggable desktop folders/shortcuts.
- **QuickTime Video Modal Engine:** Integrated video player to stream direct raw project demos (MP4/MOV) directly inside the portfolio without redirects.
- **Modular Projects Grid:** Fully responsive card layout with tech badges, categorization, live links, and repository access.
- **Glassmorphic Dock:** macOS dock with hover animations, active indicators, and custom SVG icons.

---

## 🛠️ Built With

- **HTML5** — Semantic page architecture
- **CSS3** — Custom CSS variables, Backdrop Blur Filters, CSS Grid, and Flexbox
- **Vanilla JavaScript (ES6+)** — Window state management, clock updates, modal video engine, and drag-and-drop logic
